## Ferramentas instaladas

- **uv 0.13.0:** instalador oficial, em `~/.local/bin`. Trouxe Python 3.15.0 e 3.14.8.
- **pnpm 12.11.2:**
  - O `corepack` que veio com o Node 22.11 é antigo e falhou na verificação de assinatura das chaves do registro npm (`Cannot find matching keyid`).
  - Atualizar o `corepack` exigiria sudo, porque a pasta global do npm pertence ao root.
  - Saída: instalar `@pnpm/exe`, que traz o próprio runtime, em `~/.local` com `npm --prefix`. Não precisou de sudo e não alterou o Node global.
- **Node do sistema (22.11) é velho demais para o Vite**, que exige `^20.19.0 || >=22.12.0`. O pnpm 12 fixa o Node 24.21.0 (LTS) só neste projeto via `devEngines.runtime`; testado, e o Node global continua 22.11.

  - `pyyaml` e `httptools` compilam a partir do código-fonte.
